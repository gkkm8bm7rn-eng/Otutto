# OTUTTO

Многостраничный электронный шоурум фабрики-ателье мягкой мебели. Статический HTML, CSS и небольшой браузерный JavaScript; сборка на Node.js без внешних зависимостей. 22 содержательные страницы и `404.html`.

## Локальный запуск

Нужен Node.js 20 или новее. Устанавливать пакеты через `npm install` не требуется.

```sh
npm run build
npm run check
npm run dev
```

Предпросмотр: [http://localhost:4173](http://localhost:4173). Команда `dev` собирает проект перед запуском сервера. После изменения исходников выполните сборку повторно и обновите страницу. `check` проверяет собранные страницы; это не заменяет визуальную проверку на телефоне и компьютере.

Локальный сервер предназначен для предпросмотра. Сборка не публикует сайт автоматически. По умолчанию страницы содержат `noindex, nofollow`, а `robots.txt` запрещает обход.

## Где редактировать

| Файл / папка | Содержание |
| --- | --- |
| `src/content.json` | Общие данные бренда, категории и модели диванов; ссылки на соответствующие фотографии |
| `scripts/build.mjs` | Общие HTML-шаблоны, маршруты, тексты страниц и SEO-метаданные |
| `public/style.css` | Оформление, типографика и адаптивность |
| `public/app.js` | Мобильное меню и просмотр фотографий |
| `public/images/` | Подготовленные изображения и сохранённые оригиналы |
| `public/fonts/` | Локальные кириллические и латинские шрифты, лицензии |
| `dist/` | Готовый сайт; пересоздаётся при сборке и не редактируется вручную |

Новые изображения модели добавляются в `public/images/`, затем имя файла указывается в её поле `image` в `src/content.json`. Название модели и её фотография должны соответствовать друг другу. Для Taylor Lux, Beverly и San Remo фотографии пока не подтверждены. 3D-файлы можно подключить после их получения.

## Подготовка к публикации

Результат сборки — папка `dist/`. Её можно разместить на любом статическом хостинге, который обслуживает `index.html` из каталогов. Укажите `npm run build` как команду сборки и `dist` как папку публикации. Ссылки на страницы и ресурсы относительные: размещение возможно в корне сайта или подкаталоге. Для неизвестных страниц настройте хостинг на `404.html`.

| Переменная | Значение |
| --- | --- |
| `SITE_URL` | Необязательный абсолютный публичный URL сайта для canonical, Open Graph и `sitemap.xml`; без завершающего `/` |
| `SITE_NOINDEX` | По умолчанию предпросмотр закрыт от индексации. Только значение `false` включает индексацию |

Пример сборки для согласованного домена; `example.com` заменяется реальным адресом:

```sh
SITE_URL=https://example.com SITE_NOINDEX=false npm run build
npm run check
```

Для размещения в подкаталоге укажите его в публичном URL, например `https://example.com/showroom`. Без `SITE_URL` сайт работает, но абсолютные canonical и карта сайта не формируются. Перед публичным запуском проверьте итоговый домен, ссылки, индексацию и кадрирование изображений.

Адреса и номера телефонов в текущей версии не публикуются. Формы отправки заявок, оплата, корзина и внешние системы заявок не подключены. Способ связи добавляется после выбора реального канала.
